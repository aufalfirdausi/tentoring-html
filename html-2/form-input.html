Contoh Form Input

Penjelasan Tipe Input:

  • type="text" - Input teks biasa
  • type="email" - Input email dengan validasi
  • type="password" - Input teks tersembunyi (password)
  • type="number" - Input angka saja
  • type="date" - Input tanggal dengan date picker
  • type="checkbox" - Pilihan multiple (bisa pilih lebih dari satu)
  • type="radio" - Pilihan single (hanya bisa pilih satu)
  • <select> - Dropdown menu
  • <textarea> - Area teks untuk input panjang
  • type="submit" - Tombol untuk submit form
  • type="reset" - Tombol untuk clear/reset form
